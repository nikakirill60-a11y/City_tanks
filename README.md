# 🛡️ City Tanks — ангар, прокачка и танковые бои в браузере

Танковая игра в духе **World of Tanks** на чистом стеке: **HTML + JS + CSS + Three.js**.
Ангар с 3D-танком, дерево исследований по трём нациям, бои 7×7 с бронёй, пробитием, рикошетами,
сведением и засветом. Плюс отдельный **редактор моделей**, который сохраняет танк в JSON.

```
index.html   — ангар + бой + результаты
models.html  — редактор моделей танков (JSON)
```

## 🎮 Управление в бою

| Клавиша | Действие |
|---|---|
| `W` / `S` | Вперёд / назад |
| `A` / `D` | Поворот корпуса |
| Мышь | Наведение башни и орудия |
| ЛКМ | Выстрел |
| ПКМ | Снайперский прицел (вкл/выкл) |
| `1` `2` `3` | ББ / БП / ОФ |
| `Shift` | Форсаж |
| `Esc` | Пауза |

На телефоне — джойстик слева, огонь справа, наведение тапом по экрану.

## 🏠 Ангар

- **3D-подиум**: танк вращается мышью, колесо — зум.
- **Дерево исследований**: СССР, Германия, США и ветка ПТ-САУ; 15 танков I–V уровней.
- **Экономика**: опыт копится на танке, исследование следующей машины тратит опыт предшественника,
  покупка — серебро. Награда за бой: опыт + серебро за урон, фраги, засвет и победу.
- **Характеристики**: броня по шести зонам, орудие, три снаряда, подвижность, обзор, маскировка.
- **Карусель** купленных танков, выбор активного, настройки, сброс прогресса.
- Профиль хранится в `localStorage`; рекорды уходят в Firestore (если задан конфиг Firebase).

## 💥 Бой

- **7 × 7** на ночной городской карте: игрок + 6 союзников против 7 ботов.
- **Броня и пробитие**: у каждой зоны своя толщина, приведённая броня считается от угла встречи,
  Рикошет при угле > 70° (кроме правила трёх калибров), разброс пробития и урона ±25%.
- **Орудие**: перезарядка, сведение, разброс от движения и поворота башни, ограниченные углы
  вертикальной наводки, три типа снарядов (ББ / БП / ОФ), ОФ даёт осколочный урон при непробитии.
- **Засвет и маскировка**: противник виден, только если его засветила ваша команда —
  учитывается обзор, маскировка, движение и здания, перекрывающие линию видимости.
- **Захват базы** в центре карты, таймер 7 минут, победа по уничтожению, захвату или остатку машин.
- **Криты**: пробитие может сбить гусеницу (танк обездвижен на 4 секунды).
- **Боты с ролями**: ТТ давят, СТ и ЛТ обходят, ПТ держат дистанцию; стреляют по засвеченным целям.
- **Результаты**: урон, фраги, засвет, награда, запись рекорда.

## 🧩 Редактор моделей (`models.html`)

- Сборка танка из примитивов: бокс, клин (скошенная броня), цилиндр, сфера, конус.
- Узлы: корпус, башня, орудие, катки, гусеницы, детали.
- Свойства части: тип, узел, размер, позиция, поворот, цвет, зона брони.
- Пивоты: центр вращения башни, шарнир орудия, дуло.
- ТТХ и броня редактируются прямо в редакторе.
- Тест: слайдеры вращения башни и подъёма орудия, вращение катков.
- Сохранение в браузере, **экспорт/импорт JSON**, копирование в буфер, загрузка любого танка из игры.
- Готовый JSON можно **загрузить в игру**: кнопка 📥 в ангаре → танк появляется в карусели и играется в бою.

Формат профиля (его же читает игра):

```json
{
  "version": 1, "id": "custom-tank", "name": "Новый танк",
  "armor": { "hullFront": 45, "turretFront": 45 },
  "stats": { "hp": 500, "speed": 45 },
  "gun": { "caliber": 75, "reload": 4.5, "aimTime": 2.4, "dispersion": 0.42 },
  "shells": [{ "type": "AP", "pen": 110, "damage": 110 }],
  "parts": [{ "type": "box", "kind": "hull", "size": [2.6, 1, 5], "pos": [0, 1, 0], "rot": [0,0,0], "color": "#4d5c3f" }],
  "pivots": { "turret": [0, 1.7, 0], "gun": [0, 0.4, -1.2], "muzzle": [0, 0, -3.5] }
}
```

## 🧪 Тесты

```bash
node tests/armor.test.mjs      # углы, приведённая броня, рикошеты, ОФ, криты
node tests/data.test.mjs       # ТТХ, баланс, дерево, модели, прогрессия, импорт из редактора
node tests/battle.test.mjs     # разгон, коллизии, башня, наводка, урон
node tests/sim.test.mjs        # полный бой headless: спавн, ИИ, засвет, захват, победа
node tests/structure.test.mjs  # ссылки, импорты, id, конфиги деплоя
```
Всё это гоняется в CI (`.github/workflows/tests.yml`).

## 🚀 Деплой

GitHub Pages / Vercel / Firebase — подробно в **[DEPLOY.md](DEPLOY.md)**. Сборка не нужна:
`index.html` + `models.html` + `css/` + `js/` + `vendor/` (Three.js лежит локально, CDN не нужен).

Локально:

```bash
python3 -m http.server 8000     # или npx serve .
```
